## What landed (VT-649 follow-on; makes the framework purely modular + simple to verify)
1. **Ruling #1 — dual-role manifest.** `AgentManifest.role` → `roles: frozenset[AgentRole]` (min 1). A module
   declares `{PROPOSER}`, `{EXECUTOR}`, or BOTH (the SR shape — ONE module, register once). `validate()` is
   role-set-aware (a gated `REQUEST_*` cap is legal only if EXECUTOR ∈ roles; a pure proposer declaring one is
   REJECTED). `capabilities_for_role()` strips gated caps for the proposer lane → a dual module's proposer
   facade stays side-effect-free; send power only in `execute`. `run(ctx)` dispatches by `ctx.role`.
2. **Conformance harness (`conformance.py`) — THE simple verification process.** `check_module_conformance(module)`
   (pure, raises nothing, structured per-check) + `assert_conforms(module)` (pytest). 8 checks: has_manifest,
   manifest_valid, capabilities_legal_for_roles, tool_surface_safe (reuses assert_agent_tools_safe),
   role_methods_present, proposer_gate_readonly (proposer facade raises on every gated method),
   gated_capabilities_serviced (no orphan — `GATED_METHOD_BY_CAPABILITY` single source), name_registerable.
   Tests: reference + dual-role fixtures pass ALL; one intentionally-broken module per check proves each fires.
3. **SDK boundary + README.** `__all__` = the complete public SDK (27 names) — a module imports ONLY
   `orchestrator.agent_framework`, never a submodule-deep path. `README.md` = "build + verify a module in 5 steps"
   with the dual-role SR worked example.
4. **D-REG (CL-2026-07-15-manifest-single-source-activation):** `register_activation_prereqs(module)` — EXPLICIT,
   not import-time, idempotent, drift-guarded; publishes `manifest.as_prerequisites()` into activation_registry.
   Test proves import mutates nothing; wiring publishes the bar.
5. **D-ENT (CL-2026-07-15-entitlement-computed):** `check_entitlement(manifest, tenant_id)` — SOFT, computed-from-
   billing seam; no entitlement_key → free (True); billable → soft-open (True) pre-launch w/ VT-619-metering TODO.
   Never hardcodes ₹5000, never hard-blocks.
