# VT-710 — O8 Checkpoint B (Codex)

Brief §2/§4. Spec: o8 design v0.2 §3/§5/§7.

## Scope
**Ingestion:** acquire → verify rights → hash/dedupe → quarantine raw → tool-less extraction →
schema validation → normalize claim/applicability → PII redaction → independence clustering →
embed → candidate registry. Raw text never retrieval-eligible; source text cannot self-assign
authority/confidence/applicability; taint persists; regulatory cards require jurisdiction +
effective dates; T4 stays research-only until corroborated.
**First input:** the existing 118-card `archives/business-knowledge/` corpus — rights pass
FIRST, re-key to the card schema, enter as CANDIDATES (brief §4).
**Retrieval:** the 12-step order — scope enforcement → exclude expired/superseded/quarantined →
mandatory jurisdiction + effective-period filter → explicit mismatch = exclusion → universal =
match → unknown = penalize/hedge → hybrid semantic+lexical+entity → claim-scoped authority
ranking → cluster dedup → diversity + token budget → conflicts/disputed returned explicitly →
nothing below minimum score. Per-identity budgets; Manager gets conclusions, not deep corpora.

## Exit gate
Adversarial-ingestion + source canaries (one official, one archived research, one adversarial
forum-style; fetch/embed failure FAILS the canary — egress runs handed to CC) · relevance,
isolation, latency, no-result tests · retrieval engine present but consumed by NOTHING live.
