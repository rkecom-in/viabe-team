# VT-748 — the two things the B9 and VT-744 lanes left behind

## 1. A live fail-open path next to the fix that shipped

The F3 verifier confirmed the trial-notify change is safe **and has zero production effect** — which
was expected, since the blocker text was wrong and the real cron already wires the real seam. But it
also found that the lane's actual theme, *"the owner is left uninformed"*, still has **a live
fail-open path roughly sixty lines below the fix**, which the lane did not close.

That is the more important half of B9: a path where a failure results in the owner hearing nothing,
on the money path, unalarmed. **Locate it from the F3 verification transcript, confirm it against
the code, and close it or record why it is safe.**

Note the pattern rather than just the instance: the lane fixed the thing it was told about and did
not look sixty lines further, because its brief named a specific defect and that defect was fiction.
A brief is a hypothesis.

## 2. The VT-744 audit's headline claim is wrong

`.viabe/vt744-capture-audit.md` field 3b states **"BUSINESS RESULT: CAPTURED"**. The F5 verifier
found the chain is **INERT in production** — so the audit's own most reassuring line is false.

This matters disproportionately: the audit exists precisely to say what we do and do not capture
about real tenants, and it is the input to deciding what VT-744 builds. **An audit that overstates
coverage causes exactly the gap it was written to prevent** — nobody builds capture for something
already marked captured, and the year passes unrecorded.

Correct the field with the evidence, and re-check the other CAPTURED verdicts by the same standard:
a chain that exists in code but is called by nothing is NOT captured. That test has caught five such
cases in one week.

## Boundaries

- Do not "fix" the audit by softening every verdict to PARTIAL. The point is accuracy in both
  directions; over-reporting gaps wastes the same budget as under-reporting them.
- The fail-open path is on the money path. Fail CLOSED, and if the correct behaviour is genuinely to
  proceed, say so explicitly with the reason.

## Exit gate

(a) The fail-open path is closed, or documented as safe with the mechanism named. (b) Field 3b is
corrected and every other CAPTURED verdict is re-checked against "is there a production caller".
(c) The audit states its own verification standard so the next reader knows what CAPTURED means.
