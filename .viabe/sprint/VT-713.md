## What shipped

- **Latest-first, full history** — the 30-day floor is gone; `fetchFlowPage` returns one
  DESC page (default 120 events) across all 8 sources with an older-than cursor.
- **Load-on-scroll** — `FlowStream` client component (the sim-artifact visual language moved
  client-side intact) with an IntersectionObserver sentinel calling the `loadOlderFlow`
  server action; the action RE-GUARDS (requireOpsOperator + canAccessTenant) because server
  actions are network-callable.
- **Date hotlinks** — `fetchFlowDayIndex` builds a year → month → day tree (from the two
  dominant streams' timestamps, capped 4k each); the header nav renders day chips linking
  `?before=<end-of-day>` so any date in any year is one click; "back to latest" link when
  jumped.
