# VT-725 — connect the knowledge engine to the Manager

## The gap this closes (audited 2026-08-03)
The O8 engine is COMPLETE and MERGED: `card_retrieval.py` (applicability filter, hybrid
retrieval, weighted ranking, independence-cluster diversity, per-tenant assignment overrides,
conflict surfacing, scoring traces), `admission.py`, `rollout.py`, `specialist_memory.py`,
twelve tables, 118 eligible cards.

**`grep` across `agent_graph/` returns ZERO references to any of it.** Nothing calls the
retrieval engine. The Manager cannot read a single card. O8 is built and unreachable — that is
the whole distance between "we have a moat" and "the moat does anything."

This row is the consumer. It was never rostered; that is a Clau miss, not a CC one.

## Scope — SHADOW FIRST, non-negotiable
1. **Retrieval call site at the Manager's turn.** The Manager's reasoning arc (understand →
   identify capability → define outcome → assemble framing context) gains a retrieval step when
   assembling framing context. Per-identity budget declared alongside the ACF manifest
   (o8 design §5.6): corpus domains, layers, top-k, token budget.
2. **Mode `shadow` first:** cards are retrieved, scored and LOGGED — **never injected into the
   prompt**. This produces the attribution substrate with zero behavioural risk. The flip to
   `active` (injection) is a SEPARATE step gated on the baseline comparison and on Fazal (D3).
3. **Assignment resolution honoured at retrieval:** global `knowledge_cards.default_assignment`
   overlaid with the per-tenant `knowledge_card_assignments` row. This is the flip mechanism
   Fazal ratified — `manager_global` | `manager_tenant` | `specialist:<agent>` | `disabled`,
   evaluated per retrieval, changeable at runtime without a deploy.
4. **`decision_evidence_links` populated** on every retrieval: which card versions were
   retrieved / selected / rejected, for which run and decision. This is the causality substrate
   §6 needs for ablation — without it, demotion can never be evidence-based.
5. **Specialist retrieval is narrow by construction** (§5.7): a specialist gets only its lane's
   assigned cards plus its thin tenant/task customisation memory. It never gets the Manager's
   breadth. The Manager gets specialist conclusions and cross-functional evidence, not deep
   domain corpora.

## Boundaries — the ones that must not bend
- **Retrieval is ADVISORY TO REASONING and NEVER authorizes an effect.** No customer send, no
  money action, no consent change, no gate bypass — deterministic gates and Pillar-7 remain the
  sole effect authority (ARCHITECTURE §0.1.1). A retrieved card that says "offer a discount"
  does not make a discount sendable.
- **No injection in this row.** Shadow only. If the flip to active is tempting because shadow
  looks good, that is exactly the reasoning the baseline exists to prevent.
- **Retrieval failure must be silent-safe:** a retrieval error degrades to no-cards, never to a
  failed turn. The Manager worked without cards for months; it must still.
- **No card content in logs beyond ids + scores** (`decision_evidence_links` is PII-free by
  construction; keep it that way).
- Brain-touching → full-pack ×3.

## Exit gate
On deployed dev in shadow: (a) a real owner turn produces a retrieval trace with non-zero
candidate cards and a recorded top-k; (b) a per-tenant assignment override demonstrably changes
what is retrieved for that tenant and not for another — **canary, proving the flip works at
runtime**; (c) `decision_evidence_links` rows land with retrieved/selected/rejected populated;
(d) a specialist dispatch retrieves ONLY its lane's cards — proven, not asserted; (e) forced
retrieval failure degrades to no-cards with the turn completing normally; (f) full-pack ×3 shows
no new failure class — expected, since nothing is injected; a regression here means something is
leaking into the prompt that should not be.

## What comes after (NOT this row)
The `active` flip (injection), measured against the sealed baseline. That is D3, Fazal's, and it
needs the treatment run to beat the frozen no-O8 baseline on the sealed set before it is even
askable.
